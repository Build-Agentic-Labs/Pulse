Recommended sequence

  1. Agree the reference sheet: shape, density, typography and action hierarchy.
  2. Buttons and fields: SOP annexes, AWI creation and Settings.
  3. Dialog styling and status badges, reusing the existing modal behavior.
  4. Headers, empty states and feedback across lists.
  5. Product and mobile compact/touch variants.
  6. Remove superseded styles and verify shared changes propagate.
